# Явка — учёт посещаемости учебной группы

«Явка» — приложение, которое объединяет расписание, отметки посещаемости и сводную ведомость в одном журнале. Интерфейс создан на HTML, CSS и JavaScript; браузерная версия хранит основной журнал локально, а отчёты формирует в XLSX с помощью ExcelJS.

## Журнал учебной группы

В приложении задаются список студентов и расписание, построенное на чередовании двух учебных недель. Ответственный выбирает дату и занятие, отмечает присутствующих и указывает причину отсутствия. Для одной отметки можно выбрать одну или несколько пар; каждая пара учитывается как два академических часа.

Сохранённые записи позволяют просматривать итоги по отдельному студенту или по группе за месяц и за весь период. Расчёты отражают только те занятия, для которых в журнал внесены отметки.

## Данные и отчётность

Основные сведения остаются в локальном хранилище браузера на устройстве, где ведётся журнал. Автоматического обмена между устройствами нет. Очистка данных браузера может удалить локальные записи, поэтому выгрузка и хранение резервных копий требуют отдельного внимания.

Файл XLSX предназначен для учёта пропусков: в нём собраны часы отсутствия по датам и причинам. Отметки о присутствии в эту ведомость не входят, поэтому она не является полной копией журнала.

## Ответы студентов по ссылке

В исходном коде сохранён дополнительный сценарий создания группы и сбора ответов через Firebase и Firestore. Его работа зависит от настроек облачного проекта и правил доступа. Перед использованием реальных данных студентов этот сценарий требует отдельной проверки и рассматривается как экспериментальная возможность проекта.

## Платформы и технологии

Веб-версия находится в каталоге `www`. Репозиторий также содержит настольную оболочку на Electron и мобильную основу на Capacitor. Сценарии GitHub Actions описывают публикацию веб-версии и сборку приложений для Windows и Android.

## Особенности текущей версии

Итоги зависят от полноты внесённых отметок. При сохранении занятий с пересекающимися наборами пар отдельные часы могут учитываться повторно, поэтому такие записи важно сверять перед подготовкой сводки. В онлайн-сценарии Firebase отдельно проверяются конфигурация и ограничения доступа.
